Build adjustments retained in the corresponding source:
- melonDS: treat an empty JIT_ARCH value as disabled.
- PPSSPP: compile the libpng ARM NEON initialization and filter sources for ARM64; build with RTTI and exceptions enabled.
- Stella: use strtof/strtod with full-input and errno checks because the selected NDK libc++ does not provide floating-point from_chars.
- Mupen64Plus-Next: generate ABI-specific assembler offset headers from each NDK-built asm_defines object before assembling the dynarec sources.
